### #325 の要点

```
$ curl -o /dev/null -w '%{http_code}' https://giinrecord.jp/this-does-not-exist/
200                              ← 存在しないのに 200

$ curl https://giinrecord.jp/this-does-not-exist/ | grep -oE '<html[^>]*>|<title>[^<]*</title>'
<html lang="en">                 ← 実在ページは lang="ja"
<title>Loading...</title>
```

React Router の**開発者向けメッセージ**（`💿 Hey developer 👋`）も本番に出ている。
`HydrateFallback` が未定義で、`routes.ts` に catch-all が無い。

**最大の注意点は「プリレンダー済みルートを壊さないこと」。** `try_files` を安易に
`=404` にすると全ページが落ちる。CI の `docker-web` ジョブが nginx を起動して検査しているので、
そこに追加する。

### #326 の要点

`member.tsx:253` の `folded` が `tab === "stance"` で絞られており、**発言には効かない**。

```
発言数 上位5: 1454, 1381, 1322, 1204, 1103
中央値: 68 / 100件超 282名 / 500件超 26名
```

`STANCE_FOLD = 20` を入れた #88 の理由は「会派の態度は**100行前後**になるので」。
発言はその **14 倍**である。

**ただし「重い」は未実測。** 転送は速いことが分かっている（gzip 234KB、0.187秒）ので、
問題があるとすれば描画側。**測って問題が無ければ「対応不要」で閉じる**のが正しい結論
（#275 と発言タブの転送量で、2回その前例がある）。

## 前スプリントからの適応（作業合意に追加済み・再掲）

- **テストは「戻すと落ちる」まで確かめる。1通りの戻し方では足りない**
  （#244 → #308 → #313 → #320 で**4回**繰り返した）
  1. その変更を**丸ごと削除**する
  2. **条件・比較対象を別のものに差し替える**
  3. **設計の要点だけを無効化する**
- **自分の変更が「緩和」でないことは、修正前と比べて確かめる**
  （#320 で「緩めていない」と書きながら2回緩めていた。`origin/main` の worktree で同じ入力を叩く）
- **絞り込みの手がかりには強さの順序がある。** 名簿に書いてある事実は、記載からの推論より強い
- **報告に書く数字・ID・状態は、すべて直前のツール出力から引用する**
- **マージは成果ではない。** DoD は「本番の URL で確認できる」まで
