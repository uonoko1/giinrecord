# Sprint 13（2026-08-25）

## ゴール
**会派ではなく個人にフォーカスする。** 議員ページに「その人が何をしたか」を出す。

Sprint 12 終了時点の議員ページは、多くの議員で **「すべて」と「会派の態度」しか中身が無い**状態だった。
「会派の態度」は所属会派の投票であって本人の行為ではない。本人の記録が空のまま会派の記録だけが
並ぶと、**推定が事実と構造的に並んでしまう**。これを解消することがこのスプリントの主題。

### 見せ方（見つけやすさ・正確さ）

- **#238 議員ページのタブをカテゴライズ**（PR #258）。**「本人の記録」/「所属会派の記録（推定）」**の
  2群に分割。PO 案（意思表示/提案/発言）は 1,057件全件で検証した結果、
  **772名が「見出し3つ・うち2つが空」**になり、かつ推定と事実が並ぶため却下。実装者案を採用した。
- **#239 議員一覧の見出しと絞り込み**（PR #254）。「すべての議会の議員」が二重に不正確だった
  （997名なのに「すべて」／9議会なのに「すべての議会」）。見出しが絞り込みを反映するようにし、
  `?former=1` も URL に載せた。**`?group=` に存在しない会派名を渡すと OGP に架空の会派名が出る**
  問題も同時に修正（3パラメータのうち assembly しか実在照合していなかった）。
- **#251 衆院の記録が限定される理由を明記**（PR #259）。`/coverage/` に
  「衆議院の記録が議員ページに紐づく範囲」の節を追加。

### 調査（Sprint 14 の土台）

- **#237 個人の行為として一次資料に残るものの洗い出し**（PR #241）。→ #242〜#244 を起票。
  委員会発言は**衆院 919 → 33,313（36.2倍）／参院 544 → 36,550（67.2倍）**。約30〜45MB/回次で、
  `data/members/` は現在87MB。**データサイズ対策が実質的な設計課題**であることが判明。
- **#245 回次ごとの衆院議員名簿の一次資料**（PR #249）。衆院サイトの名簿は**「現在」1枚のみ**
  （`1giin.htm`、令和8年2月18日現在）。過去分は NDL の WARP に148点あるが、
  **WARP の robots.txt が `/web/` `/20` `/collections/` を全 UA に Disallow**（例外は `JAEA-FNAA` のみ）。
  → **取得しない**と決定し、#250（NDL への問い合わせ）を人間タスクとして起票。
- **#240 議会識別子の可読性**（PR #247）。`diet` は The National Diet of Japan の正式訳で**誤りではない**。
  `pref-32` は JIS X 0401 の都道府県コード（32=島根）。結論は**案(C)＝内部 ID は維持し URL だけ slug 化**
  （301 は9本のみ）。改名直後のため**実装は Sprint 14 以降**。

## 良かったこと（継続）

- **PO 案が全件検証で却下された（#238）**。「772名が見出し3つ・うち2つ空」という**実データの反証**を
  実装者が出してきた。権威ではなくデータで決まった。
- **robots.txt を自分で確認して「取らない」と決めた（#245）**。目的の正当性を理由に robots を破れば、
  **公開データの扱いについてこのサービスが主張していることの信頼性が失われる**。
- **正確さの修正が「実測 → 反証 → 設計変更」で回った**：opacity（実測して AA 不足を反証）、
  代理値（データ更新で自動追従することを実証）、監視（スタブの前提が偽と判明）。
  いずれも「言われたから直した」ではない。
- 差し戻しは実害のある指摘のみ。握りつぶしゼロ。
