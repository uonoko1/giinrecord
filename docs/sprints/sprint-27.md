## この回でいちばん重い発見

**実装とテストが同じ未定義値を使うと、テストは恒真になる**（#699）。

`#693` で PO が `OPS.setTransform` を辿れと指示した。**pdfjs 6.2.108 に存在しない**（`undefined`）。
実装が `op === OPS.setTransform` と書き、テストも `OPS.setTransform` を投げていたら、
**`undefined === undefined` で通る。何も検査していないテストが緑になる。**

担当者が `tsc` の `TS2551` で気づいた。**型検査だけが捕まえた**——テストは捕まえない形だった。

**この回はもう 1 つ同じ形を出している**（#703）。PO が「`T*` の前に必ず `TD`/`TL` を出す」と誤って引用したが、
実測では **`T*` も `TD` も `TL` も 0 回**だった。担当者が 2 通りの数え方（pdfjs の `getOperatorList()` と
コンテンツストリームを `zlib` で解いた生トークン）で確かめて訂正した。
