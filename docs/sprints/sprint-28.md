### **`pr-closes` は本文を直しても `gh run rerun` では緑にならない**（PR #860 → #863）

**#860 の担当者がジョブのログを読んで特定した。**

**`gh run rerun` は「その run が作られた時点の本文」を再生するので、本文を編集しても反映されない。**
**空コミットを push して新しい `synchronize` イベントを起こす必要がある。**

**PO はこれを `ci.yml` のコメントに書こうとして、自分で CI を落とした**——
手元での確認方法に `gh pr view` と書いたところ、
`pr-closes.test.sh` の `assert_not_contains "$body" 'gh pr view'`（#793「CI は API を叩かない」）に当たった。
**この検査はコメントか実行の行かを区別しない。**
**検査は緩めず、手順を `docs/WORKING_AGREEMENT.md` に移した**（緩めれば実行の行も見逃す形に弱まる）。
