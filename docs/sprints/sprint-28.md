**根拠は `docs/DATA_CONTRACT.md` の「一次資料の取得と再公開（#537）」:**

| | |
|---|---|
| **採決の賛否は著作物ではない** | 著作権法 2 条 1 項 1 号の「思想又は感情を創作的に表現したもの」に当たらない |
| **公開しているのは抽出した事実だけ** | PDF の表現（レイアウト・組版・文章）を再現していない |

**取得の作法は緩めていない**（`robots.txt` を読む・1 秒以上空ける・UA を名乗る・直列・表現を再現しない）。
**新しい議会を足すときのチェックリスト 6 項目**も置き、**満たせない議会は実装しない**と決めた。

**調査文書の「禁止されていないが許可されてもいない」という一文は、法的判断ではなく
『安全側に倒す』ために置かれたものだった**——**元の記述は消さず、訂正ブロックを足した。**

## この回でいちばん重い発見

### **同じ見落としが 3 か所に複製されていた**（#746 / PR #747）

**#654 は「`/__not-found` が 200 で直接開ける」という PO の起票で、確認項目も PO が書いた。**
**人間が反映したあとスクリプトは「4 つとも期待どおり」と報告したが、PO が別の綴りで確かめたら 200 が残っていた。**

```
/__not-found/index.html   404  ← 確認項目が見ていたのはこれ
/__not-found              200  ← 「ページが見つかりません」の本文を返す
/__not-found/             200  ← 同上
```

**原因**: `try_files $uri $uri/index.html` の 2 つ目が内部解決する。**`internal` は内部解決を止めない。**

**PO が Issue にこう書いた:**

> **「確認項目を書いた人と、それを実装した人が同じ」だと、見落としがそのまま複製される。**

**その形が 3 か所にあった**——`pending-decisions.md` の 4 項目、`human-tasks.sh`、**そして smoke。**

**3 つ目は担当者が CI の赤で見つけた:**

> `smoke.ts` が「ビルドの `*/index.html` は全部 200」で掃き出しており、`__not-found/index.html` が混ざっていた。
> **本番が 200 を返していたのでスモークは穴そのものを「合格」として固定していた。**

**検査が、穴が塞がった瞬間に落ちる形になっていた。** **CI が落ちたのは良いことだった。**

### **恒真な検算は、間違った前提を裏づけて見える**（#743 / PR #748）

**#529 が「実装するなら必ず置け」と書いた錨——「`議` は 1 本の PDF で常に同じ 1 人」——は、**
**56 本で測ると 53 / 55 本という、それらしい数字を出した。**
**だが列を回しても 53 / 55 のまま出る。恒真だった。**

**実際には 2 本（第 306・322 回）で成り立たない**（会期の途中で議長が交代する）。
**恒真な検算が数字を出し続けたので、誤った前提が 6 日間もっともらしく見えていた。**

### **2 本で実装に入ると #689 の再演になる、が当たった**

**#743 は「#529 が 2 本しか開いていない」ことだけを理由に起票した PBI だったが、
56 本を測って 5 つの落とし穴が出た。** **最も危険なのは左端の `議`:**

```
議員の帯（x≈335〜780）のはるか左（x≈33〜60）に単独の「議」が立つ（5 会期で実測）
除かずに測ると 109,482 / 113,408 対が半セル以上、差の中央 2.00 セル＝表が丸ごと 1 列ずれる
しかも「数は合う」（○ の個数と賛成者数の突き合わせは通る）
```

**利用者からも、#529 が置いた検算からも見えない。**
