### **「読めないのが正しい結果」と書いてあったコメントが、事実と違った**（#922、2026-09-19）

**`packages/etl/src/sources/local/shiga/votes-pdf.ts:17` にこう書いてあった:**

> **文字層なし 3 本**: 画像 PDF。**読めないのが正しい結果**（`Kg265_250424`・`Kg274_250628`・`Kg337_sanpi-261127`）

**#922 の担当者が測ったところ、`Kg265_250424-sanpi.pdf` は画像 PDF ではなかった:**

```
CMap 無し: showText 774 回 / 空 711 回 / グリフ  63   getTextContent → 0 items,   0 chars
CMap 有り: showText 774 回 / 空   0 回 / グリフ 837   getTextContent → 318 items, 1036 chars
```

**文字層はある。pdfjs に CMap を渡していないので、全部消えていただけだった。**

**`getTextContent` が `0 items, 0 chars` を返すので、「文字層が無い」と見える。**
**例外は出ない。** **#569 の「別のものが出る」側である。**

**残り 2 本（`Kg274` / `Kg337`）はフィクスチャに無いので、まだ測れていない**——
**担当者は「0 回だった」ではなく「数えていない」と書き分けた。**
**1 本崩れたからといって 3 本とも崩れたとは書いていない。**

### **PO が本番への影響を測り直した**（担当者の報告を狭めた）

**担当者の報告は「一次資料に書いてあるのに、出ていません」だった。事実である。**
**だが「CMap を渡すとこの日の採決が読めます」と並べると、
CMap が原因で本番から消えたように読める。**

**PO が `data/` を読んだ:**

```
pref-25 の会期 = ['2026-07', '2026-06-rinji']   ← 2 つだけ
本番の採決 14 件の日付 = 20260630 / 20260722 / 20260810   ← すべて 2026 年
滋賀のフィクスチャ 6 本は、どれも本番の会期に対応していない
```

**2025-04-24 が出ていないのは `--sessions 2` の既定のため**（新しい 2 会期しか取りに行かない）。
**CMap が消したのではなく、そもそも取りに行っていない。**
**CMap を渡しても、今日の本番のデータは 1 バイトも変わらない。**

**正しくは「2 つの別々の理由で出ていない」である。**

### **それでもこの発見は重い**

1. **コードのコメントが事実と違う。** **次に誰かが「滋賀は 3 本読めないのが正しい」と読んで、そこで止まる。**

   **CMap を先に直しておかないと、「広げたら読めなかった」という誤った結論が出る。**
3. **他 10 県と `districts` では CMap の有無で 1 つも差が出なかった**（母数つきで実測）——
   **「差が無かった」も測った結果である。**

**なお CMap を渡しても空が 21 回残る**（3 本に 8/7/6 回）。**原因は未調査。**
**「CMap を渡せば空が 0 になる」とは書けない。**
