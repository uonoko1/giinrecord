## この日いちばん重い発見

### 「守っている」と書いてあるテストが、守っていなかった

**#456 のテストは、親に `font-weight: 700` を書くと実ブラウザで 400 → 700 に戻るのに緑のまま**だった
（6通りの書き方が素通り）。セレクタ文字列の完全一致でしか見ていなかったため。

**#464 で実ブラウザの computed style に変え、変異 9/9 が落ちるようになった。**
特に **TSX の `style={{ fontWeight: 700 }}`（CSS に1文字も出ない変異）でも落ちる**のが、
computed style で見る利点の証明。

### コードを直しただけでは、同じ間違いは止まらない

**#465 で `cssText` の `;;` 問題を直した直後、#470 の担当者が別の場所で同じ罠を踏みかけた。**
原因は**教訓が記録されていなかったこと**。`docs/WORKING_AGREEMENT.md` に追記した。

### WCAG は「基準そのもの」で切る

#470 が **`.row` の境界を実測**した: `16 + 13×lh ≥ 24` ⟺ **`lh ≥ 0.6154`**。
**`0.61` は落ち、`0.62` は緑。** 任意の閾値ではない。
**#413 で「110箇所が違反」と誤って起票した**（実際は全110箇所が基準を満たしていた）ことへの回答。

### 同じ原因が 1 日に 4 件 — 正規表現で言語を読んでいた

**#451**（複数行 import）／**#472**（TSX の inline style）／**#481**（鎖の外・`@media`）／
**#483**（宣言の順序・後勝ち）。**全部「テキストとして正規表現で読んでいた」ことが原因。**

`target-size.test.ts` の `declarationsFor` は既にこう書いていた:

> **自前で CSS を解析しない**——まとめ書きや後勝ちの打ち消しを正しく扱うのは難しく、
> **実際に正規表現を 2 回書き直して 2 回とも取りこぼした**。

**その通りだった。** 教訓が 1 ファイルの中にしか無く、他の検査に届いていなかった。

### パーサに変えても、同じ穴が空いた

**#472 は正規表現をやめて TypeScript の parser にした。道具は正しかった。**
それでもレビューが **7 形試して 6 形が素通り**した:

> **`style={({ fontWeight: 400 })}`（丸括弧で包むだけ）** → 素通り。
> **`style={` の直後に丸括弧が 1 つ入るだけで検査が全部無効になる**のに、何も鳴らない。

原因は **`readObject` に到達しなかった式を、何も記録せずに捨てていた**こと。
「読めない値は落とす」という番人を置いていたのに、**そもそも何も積まれない**。

**AST は「その言語を知っている」が、「あなたが何を見るべきか」は知らない。**

### 転送量が減ったことは、正しく描けている証明にならない（2 回踏んだ）

- **#468**: 議員名の字だけ（678 字）でサブセットを作ったら `.tag` が**システムフォントに落ちた**。
  「**転送量だけ見ると成功に見えていました**」
- **#477**: `fonts.ready` だけで待つと `/members` が **1,950 KB ではなく 268 KB** になり、
  **231 件のフォールバック**。`document.fonts.status === "loaded"` が要る

**箱の一致もフォールバックの証明にならない**（#468 は全角空白が落ちて 218 名が
1 グリフだけフォールバックしたのに、箱は 997 件すべて 0 差だった）。

### サンプルでは原理的に集まらないものがある

#468 は「議員ページ 20 件のサンプル + HTML 走査」で字を集めたが、
**`.member-position`（会議録の役職の原文）は #242 により HTML に一切焼き込まれない**ので、
**何件サンプルしても集まらない**（68 字。本番 HTML に 0 件を PO が確認）。

**#477 の担当者が字集めを「HTML 全 1,466 ページ ∪ `data/` の該当欄」に変えて塞いだ。**

## つまずいたこと

- **リリースの `ref` に短縮 SHA を渡して失敗した。**
  `actions/checkout` は `+refs/heads/<ref>*` で fetch するので、**フル SHA しか解決できない**。
  **checkout の段階で落ちるため、原因がリリース内容だと誤読しやすい。** `docs/ops/deploy.md` に追記
- **#457（#451）が3度、穴のある形で出てきた。**
  1回目 `/^\s*import\s/`（`export … from` が素通り）→ 2回目 行単位のまま（**複数行 import** が素通り）→
  3回目 **正規表現の連結を間違えて何も検出しなくなった**。
  **PO が TypeScript のパーサで 18/18 通る形を検証して渡した。**
  **根本の問題は「検査器自身のテストが無い」こと**で、検査が死んでも緑になる
