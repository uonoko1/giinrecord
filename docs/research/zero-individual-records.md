# 個人の記録がゼロの 49 名を分類する調査（Issue #309）

調査日: 2026-08-30。対象は `origin/main`（`b5c897c8`）の `data/`。
`data/` は変更していない。ETL は実行していない。会議録 API への問い合わせは**件数だけを引く読み取り**（`maximumRecords=1` で `numberOfRecords` を読む）で、間隔 ≥ 1.2 秒、計 57 リクエスト。

## 結論（先に）

1. **49 名のうち 4 名は `unmatched.json` に該当があった**（延べ **66 行**）。すべて**第217回・参議院の会議録**にある発言で、衆院名簿が第221回しか無いため在職を確認できず落ちている。
2. しかしそれ以外の 45 名は `unmatched.json` に 1 行も無い。**衆院 42 名は全員、第221回・衆議院の会議録に発言が 0 件**（一次資料の側に無い）。**参院 7 名は全員、第216〜221回・参議院の会議録に発言が 0 件**（うち 6 名は第216回で任期満了）。
3. 一方 `unmatched.json` 692 行のうち **391 行（37 名分）は第221回の現職**で、**これは直せる欠落**である。ただしその 37 名は 49 名の**いずれでもない**（すでに別経路で記録が付いている議員）。**49 名の記録は、この修正では増えない。**

つまり **49 名がゼロなのは、ほぼすべて「一次資料の側に無い」**。ただし調査の途中で、**49 名とは別の 37 名について 391 行の取りこぼし**が見つかった。

## 1. 測り方

### 49 名の数え方

「個人の記録」＝ `timeline` の kind が `speech` / `bill` / `question` の行と、`data/members/{id}/speeches.json` の `speeches` 配列の要素。
`stance`（会派の態度）・`vote`・`committeeRole`・`attendance` は本人の発意による記録ではないので除く。

```
$ node (data/members/*.json を走査。assemblyId が diet-* のものだけ)
diet by house: {"shugiin":465,"sangiin":307}   （772 名）
zero: 49 {"shugiin":42,"sangiin":7}
```

Issue #309 に書かれた 49（衆 42 / 参 7）と一致した。

**49 名は全員 `data/members/{id}/speeches.json` というファイル自体が存在しない**（`speechesFileExists: 0/49`）。
参考までに `speeches.json` を持つ議員は 696 名、収録されている発言は延べ 85,068 件だった。

### `speechId` から回次と院を読む

NDL の `speechID` は `1` + 回次3桁 + **院コード1桁** + 会議コード… の形をしている。院コードは実データで検証した。

```
$ node (696 名の speeches.json を speechId の先頭 5 文字で集計)
{"sangiin:12161":4258,"sangiin:12171":25533,"sangiin:12181":477,
 "sangiin:12191":5684,"sangiin:12201":181,"sangiin:12211":23582,
 "shugiin:12210":25353}
```

参院議員の発言はすべて 5 文字目が `1`、衆院議員の発言はすべて `0`。よって **`1` = 参議院の会議録、`0` = 衆議院の会議録**。

## 4. 直せるものと直せないもの（受け入れ条件 3）

### 直せない: 49 名のゼロそのもの

- **衆院 42 名**: 第221回の衆議院の会議録に発言が無い。名簿は第221回しか無いので、それ以外の回次を突合の対象にできない（`docs/DATA_CONTRACT.md` の原則）。**取得先を足しても名寄せの規則を変えても増えない。**
- **参院 7 名**: 第216–221回の参議院の会議録に発言が無い。第200–215回にはあるが、その回次の参院名簿が公開されていない（#274 の調査どおり、在職開始日にあたる一次資料が参議院のサイトに無い）。**推測で紐づけない以上、増やせない。**

### 直せる（ただし 49 名は増えない）: 参議院の会議録にいる衆院議員 391 行

`unmatched.json` 692 行を、名簿の同名の人数で分けた。

```
$ node (data/unmatched.json × data/members/*.json)
名簿に同名 1 人: 620   同名 2 人以上: 0   名簿に無し: 72
回次別: 217 → 1人:198 / 無し:53
        219 → 1人: 31 / 無し:19
        221 → 1人:391 / 無し: 0
```

**第221回の 391 行（37 名分）は、全員が現在の衆院名簿にいる現職**である。第221回は衆院名簿が覆う回次そのものなので、**参院側の突合に衆院名簿も渡せば、在職を名簿から確認したうえで紐づけられる**（推測ではない）。一次資料で 1 件確認した。

```
$ curl "https://kokkai.ndl.go.jp/api/speech?speechID=122115391X00120260723_011&recordPacking=json"
session = 221
nameOfHouse = 参議院
nameOfMeeting = 沖縄・北方問題及び地方に関する特別委員会、総務委員会連合審査会  第1号
speaker = 簗和生
speakerGroup = 自由民主党・無所属の会
speakerPosition = None
```

連合審査会など、衆院議員が参議院の会議に出る会議録である。

**ただしこの 37 名は 49 名のいずれでもない**（37 名と 49 名の重なりは 0）。37 名のうち 36 名はすでに `speeches.json` を持っており、この修正で増えるのは件数だけである。残る 1 名（松野 博一 `h_a7c83abbb5`）は `speeches.json` を持たないが、`bill` を 1 行持つので 49 名には入っていない。

いずれにせよ **49 名は 1 人も減らない**。

### 直せない: 第217回・第219回の 229 行（うち 49 名分は 66 行）

第217回・第219回は**衆院名簿が覆っていない回次**である（名簿は第221回のみ）。氏名が一致し同名が 1 人しかいなくても、その回次に在職していたことを名簿から確認できない（`tenureVerified` の (a) も (b) も成り立たない。衆院の `terms` に `sessionTo` も `to` も 1 件も入っていない）。

第217回は 2025年10月の総選挙より前の回次で、当時の議席と第221回の議席は同じではない。**同姓同名の別人でないことを一次資料から確認できないまま紐づけるのは #230 で外したのと同じ経路**なので、紐づけない。

つまり、世耕 弘成の 61 行を含む 66 行は「取得できているが紐づけてよいと言えない」であって、「直せる」ではない。**衆議院の回次ごとの議員名簿が公開されない限り直らない。**

| 対象 | 行数 | 直せるか |

| 第221回・参議院の会議録の衆院議員 | 391 | **直せる**（名簿が覆う回次。49 名は含まれない） |
| 第217・219回・参議院の会議録の衆院議員（名簿に同名 1 人） | 229 | 直せない（名簿がその回次を覆っていない。うち 66 行が 49 名分） |
| 名簿に同名が 1 人もいない | 72 | 直せない（名簿に無い） |
| 合計 | 692 | |

## 5. 議員ページか `/coverage/` に説明を出すか（受け入れ条件 5）

### 判断

**`/coverage/` には足さない。議員ページにも文言は足さない。**

理由は 3 つある。

1. **同じことを 2 度書かない。** 参院 7 名が第200–215回で紐づかないのは、`/coverage/` の「議員ページに紐づかない回次」がすでに書いている事実である（名簿の公開範囲と、在職を確認できない氏名一致では紐づけないこと）。衆院が第221回の名簿 1 回次分しか突合できないことも、`/coverage/` の衆院名簿の節がすでに書いている。**49 名という数は、その 2 つの事実から出てくる結果であって、新しい事実ではない。**

2. **議員ページの空タブは、すでに「記録はありません。」と答えている**（`apps/web/app/routes/member.tsx`）。件数 0 のタブを隠さないのは「無いことが情報だから」という既存の判断で、これはそのまま正しい。ここに「収録した範囲に記録がない」と言い換えた説明を足すと、**42 名については「一次資料に発言が 0 件」なのに「収録の都合で出ていない」と読める**ので、事実より弱く（誤って）伝わる。

3. **今回の調査で 49 名について新たに分かったのは「一次資料の側に無い」ことで、これは画面に足す説明ではなく、この文書に残す事実である。** 画面に出すべき新しい事実があるとすれば、それは第201回以前の未収録のような**収録範囲の話**で、それはすでに `/coverage/` にある。

### 一方、直すべきもの

第221回の 391 行（37 名分）は**画面の説明ではなく ETL の修正**で扱う。参院側の突合に衆院名簿も渡す。別 PBI にする。

### もし将来書くとしたら（文案）

`/coverage/` の発言の節に、次の 1 文を足す形になる。**いまは足さない**（上の理由 1）。

> 会議録には、他院の議員が連合審査会などで発言した記録も載ります。発言した議員の院の名簿がその回次を覆っている場合にかぎり議員ページに紐づけます。覆っていない回次の発言は、会議録には残りますが議員ページには出ません。

「活動がない」「発言していない」とは書かない。書くのは**収録と突合の範囲**だけである。
