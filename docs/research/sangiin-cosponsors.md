# 参法の共同発議者・賛成者名の一次資料調査（Issue #63）

調査日: 2026-08-23。対象は第221回国会（特別会）の参法、比較用に第217回。取得は `curl -A "Mozilla/5.0"`、間隔 ≥ 0.5 秒。

## 結論

**参法の発議者全員・賛成者の氏名を載せる一次資料は、参議院・衆議院・国立国会図書館のいずれの公開サイトにも無い。**
議案情報・提出法律案 PDF・参議院法制局・参議院公報（Web 版）・衆議院の経過ページは、いずれも「筆頭者君 外N名」の形でしか記さない。
国会会議録の委員会冒頭「出席者」には「発議者」の肩書きで氏名が載るが、それは**その日に出席した発議者**であり全員ではない（217 参法 7 は「外2名」＝3人に対し出席 2 人）。付託されなかった参法（221 では 21 件中 20 件）には会議録の記録自体が無い。賛成者の氏名はどこにも載らない。

よって `Bill.submitters` は現状どおり筆頭者のみ、`supporters` は空のまま。/about の「記録にないこと」に追記した。

## 調べた資料と証拠

### 1. 参議院 議案情報（議案詳細ページ）— 筆頭者のみ

`https://www.sangiin.go.jp/japanese/joho1/kousei/gian/221/meisai/m221100221016.htm`（221 参法 16）

```
発議者
打越さく良君 外9名
提出者区分
議員発議
```

同 221 参法 11（m221100221011.htm）: `発議者 舟山康江君 外4名`。217 参法 7（217/meisai/m217100217007.htm）: `発議者 石橋通宏君 外2名`。
as-of: ページは審議の進行で変わる（経過ブロック）が、発議者欄は提出時のまま。

### 2. 提出法律案 PDF — 氏名なし

議案ページの「議案等のファイル」が指す `https://www.sangiin.go.jp/japanese/joho1/kousei/gian/221/pdf/t1002210162210.pdf`（4 ページ）。
pypdf で全文抽出し、`発議`・`賛成者`・`打越` のいずれも出現しない。表紙は

```

第一条 …
```

で始まり、末尾は「理 由 … これが、この法律案を提出する理由である。」で終わる。提出者名の頁は無い。

### 3. 参議院法制局 参法一覧 — 筆頭者のみ

の形。法制局の法案 PDF（`sanhoudata/221/221-016.pdf`、7 ページ、縦書き）も全文に `発議`・`賛成者`・筆頭者名が無い。

### 4. 参議院公報（Web 版）— 「議案提出」欄が無く、本会議の記事も「外N名発議」

回次の索引 `https://www.sangiin.go.jp/japanese/joho1/kousei/koho/221/koho.htm` は `<select name="yyyymm">` と `<select name="day">` で日付ページ `koho/221/kohoYYYYMMDD.htm`（221 は 104 日分）へ飛ぶ。日付ページが持つ記事リンク `koho/koNNN….htm` の種別を 104 日分すべて集計すると

```

 31 240 議事経過
 31 060 議事日程
  8 313 参議院改革協議会
  5 070 会議
  2 479 （歓迎に関する件）
  2 260 常任委員長懇談会経過
  1 479 議案経過表
  1 100 常任委員長懇談会
```

で、紙の公報にある「議案提出」「請願」などの欄は Web 版には無い。
参法 16 の提出日（7/9）とその翌日（7/10）の全記事（ko060/ko110/ko240/ko270）に `水俣`・`打越` は出現しない。
本会議の「議事経過」（ko240）31 件を全文検索すると、発議者に触れるのは 7/24 の

```

　案 (奥村祥大君外三名発議)
```

の 1 箇所だけで、やはり「外三名」。会期末の「議案経過表」（ko479202607251081.htm）は件名の一覧で発議者欄が無い（`打越` は文書質問の提出者としてのみ出現）。

### 5. 国会会議録検索システム API — 出席した発議者のみ（部分的）

`https://kokkai.ndl.go.jp/api/speech?sessionFrom=221&sessionTo=221&nameOfHouse=参議院&speaker=会議録情報&any=発議者&recordPacking=json`
（`speakerPosition=発議者` は 0 件。肩書きは本文側の出席者欄にしか無い。）

221 の参議院で出席者欄に「発議者」を含む会議録は 6 件。うち参法は農林水産委員会の 2 件だけ（他は衆法・憲法審査会で発議者は衆議院議員）。

第14号（2026-07-09、`https://kokkai.ndl.go.jp/txt/122115007X01420260709/0`）:

```
　　　　　　　発議者　　　　　　舟山　康江君
　　　　　　　発議者　　　　　　徳永　エリ君
　　　　　　　発議者　　　　　　高橋　光男君
　　　　　　　発議者　　　　　　杉本　純子君
　　　　　　　発議者　　　　　　岩渕　　友君
…
○主要農作物の優良な品種を確保するための公的新品種育成の促進等に関する法律案（参第一一号）
```

この日は 5 人＝「舟山康江君 外4名」と一致するが、第16号（7/16）の出席発議者は `舟山康江, 徳永エリ` の 2 人。
217 参法 7（「石橋通宏君 外2名」＝3 人）は厚生労働委員会 第14〜16号の 3 回とも出席発議者が `石橋通宏, 田村まみ` の 2 人で、**3 人目は会議録のどこにも現れない**。

- 載るのは「出席した発議者」という事実であり、発議者全員の一覧ではない（人数が一致する日があっても、それを全員と断定するのは推定になる）。
- 付託されない参法には会議録が無い（221 参法 21 件中、委員会に掛かったのは参法 11 の 1 件）。
- 会議録の公開は約 1 か月遅れる（7/24 本会議の議案は 8/23 時点で未収録）。
- 賛成者の記載は無い。
- 本会議の趣旨説明は「発議者を代表して」1 人が行うのみ。

解析自体は容易（出席者欄の `発議者　氏名君` 行の正規表現 ＋ 「本日の会議に付した案件」の `（参第N号）`）だが、上記の性質から `Bill.submitters` の「発議者」としては採らない。採るなら別の事実「委員会に発議者として出席」として扱うべきで、このリポジトリの現在の型には無い（必要なら別 Issue）。

### 6. 衆議院 議案情報 経過ページ（参法）— 筆頭者のみ

`https://www.shugiin.go.jp/internet/itdb_gian.nsf/html/gian/keika/1DE213E.htm`（221 参法 1）:

```
議案提出者 竹詰 仁君外一名
```

衆法にある「議案提出者一覧」「議案提出の賛成者」の欄は参法には無い（DATA_CONTRACT「氏名の欄が無い議案（閣法・参法）は省略」のとおり）。
