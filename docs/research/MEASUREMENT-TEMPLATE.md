## 必ず守ること（必須）

<!-- **この箇条書きは `scripts/po/measure-pbi.sh` がそのまま写します。行を消さないこと。** -->

- **専用の git worktree で作業する**（`git worktree add`）。**`pnpm install` を worktree の中で先に**（#588）。作業ファイルは `.measure/`（#797）。
- **`data/` を書き換えない。ETL の実装もしない**——**これは測定である。** 実装は別 PBI にする。
- **既存県のコードを変えない。** 罫線・文字は `pdf-table.ts` の関数をそのまま呼ぶ（再実装しない）。
- **`docs/research/local-assemblies.md` は自分の県の節だけを触る。** 他県の節と、既に書かれた測定文書は書き換えない。
- **他の担当者の worktree に触らない。**
- **変異を当てる前に無改造で緑を確認する**（#517）。変異は `scripts/dev/mutate.sh` で当て、必ず戻し、毎回 `git status --porcelain` が空であることを見る。
- **当たらなかった変異（`mutate.sh` が exit 3）を「落ちた」と数えない。**
- **「全部一致した」は測れていない徴候として扱う**（#689 の担当者自身の言葉）。**まず測り方を疑う。**
- **推測で議員を紐づけない**（#569）。**分からないことは「分からない」と書く。**
- **破壊的な git を打たない**（#618）。`git checkout` / `git restore` / `git reset --hard` / `git clean` / `git stash` を使わない。
